## Default Permission

Default permissions for NovaProxy Android VPN bridge

#### This default permission set includes the following:

- `allow-prepare-vpn`
- `allow-start-vpn`
- `allow-stop-vpn`
- `allow-get-vpn-status`
- `allow-get-native-lib-dir`
