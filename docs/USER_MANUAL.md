# NovaProxy 用户手册与使用指南 (User Manual & FAQ)

---

## 1. 安装与卸载

### 1.1 系统要求
- **操作系统**：Windows 10 (1809 及以上) 或 Windows 11 (64 位版本)
- **运行环境**：内置 Microsoft Edge WebView2 运行时（Windows 10/11 默认已预装）
- **硬件架构**：x86_64 (AMD64)
- **权限要求**：
  - 普通系统代理模式：普通非管理员权限即可正常使用。
  - TUN 模式：需要管理员权限以加载虚拟网络适配器驱动（客户端内置一键 UAC 提权功能）。

### 1.2 安装方式
- **标准安装包 (`NovaProxy_0.1.0_x64-setup.exe`)**：
  - 双击安装包，跟随安装向导完成安装；
  - 自动创建桌面快捷方式与开始菜单项；
  - 自动注册 `novaproxy://` 与 `clash://` 协议关联。
- **免安装便携版 (`NovaProxy-0.1.0-windows-x64-portable.zip`)**：
  - 解压至任意不含中文与特殊字符的文件夹；
  - 直接双击 `NovaProxy.exe` 即可运行，所有配置及数据库存放在用户本地目录。

### 1.3 卸载说明
- 通过 Windows「设置」->「应用」->「已安装的应用」选择 NovaProxy 卸载。
- 卸载程序会自动恢复系统代理至干净状态，并清理开机自启与 URL Scheme 注册表项。

## 2. 快速入门

### 2.1 导入订阅或节点
NovaProxy 提供极为灵活的多样化导入途径：
1. **订阅链接一键导入**：
   - 进入左侧导航「订阅管理」页面，点击右上角「添加订阅」；
   - 粘贴机场或服务商提供的订阅 URL，填写名称，点击保存；
   - 客户端将自动识别订阅格式（Base64、Clash YAML、sing-box JSON 等）并拉取节点。
2. **网页一键唤醒导入 (Deep Link)**：
   - 在支持一键导入的机场用户中心，直接点击「导入到 Clash」或「导入到 NovaProxy」；
   - 浏览器将自动唤醒 NovaProxy 并弹窗确认导入。
3. **剪贴板批量导入**：
   - 复制任意多行分享链接（如 `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://` 等）；
   - 在「订阅管理」页面点击「从剪贴板导入」，客户端将一次性解析并入库。
4. **屏幕二维码扫描识别**：
   - 屏幕上显示节点或订阅二维码时，点击「屏幕截图识别」；
   - 客户端将在多显示器桌面中瞬时捕获并自动解码。

### 2.2 节点测速与选择
1. 进入「节点列表」页面；
2. 点击右上角「全部测速」按钮，客户端将通过并发非阻塞 TCP Ping 测量所有节点的真实往返时延（RTT）；
3. 点击任意节点卡片，即可设为当前活动节点；
4. 若内核当前已在运行，NovaProxy 采用 **Clash API 零停机热切换** 机制，在 5 毫秒内内存无感换线，不会掐断当前已有的下载或连接。

### 2.3 启动代理
- 进入「仪表盘」页面，点击中央发光的电源大开关；
- 状态变为「已连接」，系统代理即可生效；
- 界面将实时显示当前的上传/下载速度双曲线与活动节点信息。

## 3. 工作模式说明

| 模式 | 适用场景 | 原理与特性 |
|---|---|---|
| **系统代理模式 (WinINet)** | 网页浏览、日常办公软件 | 设置 Windows 系统的全局 HTTP/SOCKS 代理设置，Chrome、Edge、微信等主动遵循系统代理的应用生效。极低资源占用。 |
| **TUN 虚拟网卡模式** | 游戏加速、命令行终端、不支持代理配置的专业软件 | 通过 Wintun 虚拟网卡在网络层接管操作系统全部 TCP/UDP/ICMP 流量，所有流量透明过代理。需要管理员权限。 |

## 4. 分流规则与 DNS 配置

NovaProxy 在「分流规则」页面提供了直观高效的流量路由控制：

- **路由模式选择**：
  - **绕过大陆与局域网 (推荐)**：国内网站与局域网 IP 直连访问，国外被墙站点经由代理加速，保障国内服务最高速、最低延迟。
  - **全局代理**：所有访问流量无条件经过代理节点。
  - **全局直连**：不经过代理，所有流量直连。
- **内置安全分流集**：
  - 私有保留网段自动直连（`10.0.0.0/8`, `192.168.0.0/16` 等）。
  - 恶意广告与追踪域名自动拦截（Reject/Block）。
  - 大陆 GeoSite / GeoIP 域名与 IP 数据库智能分流。
- **自定义分流规则**：
  - 支持按域名后缀（`DomainSuffix`）、IP 网段（`IpCidr`）、端口（`Port`）、目标进程名（`ProcessName`）添加自定义规则；
  - 规则支持上下拖拽微调优先级，命中即按设定动作（代理、直连、阻断）执行。
- **DNS 防污染与 Fake-IP**：
  - 国内域名采用国内优质 DNS（如 223.5.5.5）直连解析；
  - 国外域名经由加密 DoH（DNS-over-HTTPS）安全解析，杜绝 DNS 劫持；
  - 支持 Fake-IP 模式，规避本地 DNS 泄露并提升首包响应速度。

## 5. 常见问题排查 (FAQ)

### Q1：关闭客户端后电脑无法上网（网页打不开）怎么办？
**答**：NovaProxy 具备独创的**系统代理基线快照与异常还原机制**，退出客户端或进程异常终止时，均会自动将系统代理还原为启动前的基线状态。
如果由于第三方软件冲突导致异常，可在 NovaProxy「系统设置」中点击「验证 SQLite 完整性」，或在 Windows「设置」->「网络和 Internet」->「代理」中关闭「使用代理服务器」。

### Q2：启动 TUN 模式提示需要管理员权限？
**答**：TUN 虚拟网卡驱动（Wintun）需要在 Windows 网络协议栈中挂载虚拟适配器，这是 Windows 操作系统的强制安全限制。
在 NovaProxy「系统设置」页面中，点击「以管理员身份重新启动」，并在系统弹出的 UAC 提示窗口中选择「是」即可一键平滑提权。

### Q3：本地 7890 端口被占用怎么办？
**答**：NovaProxy 内置了**端口冲突自动顺延**（Auto Port Fallback）机制。若 7890 端口已被其他服务占用，客户端会自动探针可用端口并平滑重写配置文件，无需手动修改。您也可以在「系统设置」中自定义本地混合监听端口。

### Q4：网络从 Wi-Fi 切换或电脑休眠唤醒后掉代理？
**答**：NovaProxy 运行了基于 Win32 `NotifyAddrChange` 的原生网络状态监听线程，一旦检测到网络适配器切换或 IP 变动，会在纳秒级自动向 Windows 发送 `INTERNET_OPTION_SETTINGS_CHANGED` 广播，确保代理持续有效。

### Q5：遇到未知错误如何向开发者反馈？
**答**：
1. 进入「系统设置」页面；
2. 找到「诊断与容灾备份」卡片，点击「复制诊断报告」；
3. 客户端会自动对敏感凭据（如密码、UUID、密钥）进行脱敏掩码，将包含客户端版本、运行内核、最近日志与系统环境的结构化报告复制到剪贴板，您可以直接粘贴到 GitHub Issue 中进行反馈。
